## v2.returns.get_return_list

**Method:** `GET`  
**Path:** `/api/v2/returns/get_return_list`

Use this api to get detail information of many return by shop id.

### Endpoints

| Environment | URL |
| --- | --- |

| Brazil | `https://openplatform.shopee.com.br/api/v2/returns/get_return_list` |
| Test/Sandbox | `https://partner.test-stable.shopeemobile.com/api/v2/returns/get_return_list` |
