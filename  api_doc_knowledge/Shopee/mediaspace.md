## v2.media_space.init_video_upload

**Method:** `POST`  
**Path:** `/api/v2/media_space/init_video_upload`

Initiate video upload session.

Video duration should be between 10s and 60s (inclusive).

### Endpoints

| Environment | URL |
| --- | --- |
| Production | `https://partner.shopeemobile.com/api/v2/media_space/init_video_upload` |
| Chinese Mainland | `https://openplatform.shopee.cn/api/v2/media_space/init_video_upload` |
| Brazil | `https://openplatform.shopee.com.br/api/v2/media_space/init_video_upload` |
| Test/Sandbox | `https://partner.test-stable.shopeemobile.com/api/v2/media_space/init_video_upload` |

### Common Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| partner_id | int |  | 1 | Partner ID is assigned upon registration is successful. Required for all requests. |
| timestamp | timestamp |  | 1610000000 | This is to indicate the timestamp of the request. Required for all requests. Expires in 5 minutes. |
| access_token | string |  | c09222e3fc40ffb25fc947f738b1abf1 | The token for API access, using to identify your permission to the api. Valid for multiple use and expires in 4 hours. |
| shop_id | int |  | 600000 | Shopee's unique identifier for a shop. Required param for most APIs. |
| sign | string |  | e318d3e932719916a9f9ebb57e2011961bd47abfa54a36e040d050d8931596e2 | Signature generated by partner_id, api path, timestamp, access_token, shop_id and partner_key via HMAC-SHA256 hashing algorithm. More details:  https://open.shopee.com/documents?module=87&type=2&id=58&version=2 |


### Request Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| file_md5 | string | ✅ | 2abf0b6e5ff90ff24437a0808f171a93 | md5 of video file |
| file_size | int | ✅ | 1261876 | size of video file, in bytes, maximum is 30MB |


### Response Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| message | string |  |  | Indicate error details if hit error. Empty if no error happened. |
| request_id | string |  | 2f047a807e0e482188c5dac9b69bf90e | The identifier of the API request for error tracking |
| response | object |  |  |  |
| ↳ video_upload_id | string |  | sg_90ce045e-fd92-4f0b-97a4-eda40546cd9f_000000 | The identifier of this upload session, used in following video upload request and item creating and/or updating |
| error | string |  |  | Indicate error type if hit error. Empty if no error happened. |

## v2.media_space.upload_video_part

**Method:** `POST`  
**Path:** `/api/v2/media_space/upload_video_part`

Upload video file by part using the upload_id in initiate_video_upload.

The request Content-Type of this API should be of multipart/form-data

| Environment | URL |
| --- | --- |
| Production | `https://partner.shopeemobile.com/api/v2/media_space/upload_video_part` |
