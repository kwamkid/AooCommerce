## v2.account_health.get_shop_performance

**Method:** `GET`  
**Path:** `/api/v2/account_health/get_shop_performance`

The data metrics of shop performance.


### Endpoints

| Environment | URL |
| --- | --- |
| Production | `https://partner.shopeemobile.com/api/v2/account_health/get_shop_performance` |
| Chinese Mainland | `https://openplatform.shopee.cn/api/v2/account_health/get_shop_performance` |
| Brazil | `https://openplatform.shopee.com.br/api/v2/account_health/get_shop_performance` |
