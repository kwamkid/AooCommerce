## v2.discount.add_discount

**Method:** `POST`  
**Path:** `/api/v2/discount/add_discount`

Use this api to add shop discount activity

### Endpoints

| Environment | URL |
| --- | --- |
| Production | `https://partner.shopeemobile.com/api/v2/discount/add_discount` |
| Chinese Mainland | `https://openplatform.shopee.cn/api/v2/discount/add_discount` |
| Brazil | `https://openplatform.shopee.com.br/api/v2/discount/add_discount` |
| Test/Sandbox | `https://partner.test-stable.shopeemobile.com/api/v2/discount/add_discount` |

### Common Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| partner_id | int |  | 1 | Partner ID is assigned upon registration is successful. Required for all requests. |
| timestamp | timestamp |  | 1610000000 | This is to indicate the timestamp of the request. Required for all requests. Expires in 5 minutes. |
| access_token | string |  | c09222e3fc40ffb25fc947f738b1abf1 | The token for API access, using to identify your permission to the api. Valid for multiple use and expires in 4 hours. |
| shop_id | int |  | 600000 | Shopee's unique identifier for a shop. Required param for most APIs. |
| sign | string |  | e318d3e932719916a9f9ebb57e2011961bd47abfa54a36e040d050d8931596e2 | Signature generated by partner_id, api path, timestamp, access_token, shop_id and partner_key via HMAC-SHA256 hashing algorithm. More details:  https://open.shopee.com/documents?module=87&type=2&id=58&version=2 |


### Request Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| discount_name | string | ✅ | test-create | Title of the discount. |
| start_time | timestamp | ✅ | 1624864213 | The time when discount activity start.The start time must be 1 hour later than current time. |
| end_time | timestamp | ✅ | 1625382613 | The time when discount activity end.The end time must be 1 hour later than start time,and the discount period must be less than 180 days. |


### Response Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| message | string |  |  | The description of error code |
| error | string |  |  | Error code |

| response | object |  |  |  |
| ↳ discount_id | int |  | 665123666665499 | Shopee's unique identifier for a discount activity. |
