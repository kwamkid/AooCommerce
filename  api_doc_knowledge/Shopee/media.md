## v2.media.upload_image

**Method:** `POST`  
**Path:** `/api/v2/media/upload_image`

Use this API to upload images and support different business scenarios through business and scene parameters.

### Endpoints

| Environment | URL |
| --- | --- |
| Production | `https://partner.shopeemobile.com/api/v2/media/upload_image` |
| Chinese Mainland | `https://openplatform.shopee.cn/api/v2/media/upload_image` |
| Brazil | `https://openplatform.shopee.com.br/api/v2/media/upload_image` |
| Test/Sandbox | `https://partner.test-stable.shopeemobile.com/api/v2/media/upload_image` |

### Common Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| partner_id | int |  | 1 | Partner ID is assigned upon registration is successful. Required for all requests. |
| timestamp | timestamp |  | 1610000000 | This is to indicate the timestamp of the request. Required for all requests. Expires in 5 minutes. |
| sign | string |  | e318d3e932719916a9f9ebb57e2011961bd47abfa54a36e040d050d8931596e2 | Signature generated by partner_id, api path, timestamp and partner_key via HMAC-SHA256 hashing algorithm. More details:  https://open.shopee.com/documents?module=87&type=2&id=58&version=2 |


### Request Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| business | int32 | ✅ | 2 | Defines the business type of the uploaded image. Supported values:&nbsp;2 = Returns |
| scene | int32 | ✅ | 1 | Defines the purpose of the uploaded image under the specified business type.&nbsp;Supported values:- If&nbsp;business = 2 (Returns): 1 = Return Seller Self Arrange Pickup Proof Image |
| images | file | ✅ |  | The image files to be uploaded. Rules and restrictions by business and scene:- If business = 2 (Returns) and scene = 1 (Return Seller Self Arrange Pickup Proof Image): Up to&nbsp;3&nbsp;images can be uploaded. Each image must not exceed&nbsp;10MB. Supported formats:&nbsp;JPG, JPEG, PNG. |


### Response Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| error | string |  |  | Indicate error type if hit error. Empty if no error happened. |
| message | string |  |  | Indicate error details if hit error. Empty if no error happened. |
| warning | string |  |  | Indicate warning message you should take care. |
| request_id | string |  |  | The identifier for an API request for error tracking. |
| response | object |  |  |  |
| ↳ image_list | object[] |  |  | List of uploaded images. |
| ↳ ↳ image_id | string |  |  | Unique ID of the uploaded image. |
| ↳ ↳ image_url | string |  |  | URL of the uploaded image. |


### Request Example (Python)

```python
import requests
import json

url = "https://partner.shopeemobile.com/api/v2/media/upload_image?partner_id=partner_id&sign=sign&timestamp=timestamp"

payload={}
files=[
  ('images',('images',open('/path/to/file','rb'),'application/octet-stream')) # Replace with actual file path
]
headers = {

}
response = requests.RPCRequest("POST",url,headers=headers, data=payload, files=files, allow_redirects=False)

print(response.text)

```

### Request Payload

```json
{
	"business": 2,
	"scene": 1,
	"images": "path/to/file"
}
```

### Response Example

```json
{
    "error": "",
    "message": "",
    "request_id": "e3e3e7f33e59c815329b4ac9cc52c501",
    "response": {
        "image_list": [
            {
                "image_id": "test_image_id",
                "image_url": "test_image_url"
            }
        ]
    },
    "warning": ""
}
```

## v2.media.init_video_upload

**Method:** `POST`  
**Path:** `/api/v2/media/init_video_upload`

Use this API to initialize a new video upload task and obtain a unique upload session ID.

### Endpoints

| Environment | URL |
| --- | --- |
| Production | `https://partner.shopeemobile.com/api/v2/media/init_video_upload` |
| Chinese Mainland | `https://openplatform.shopee.cn/api/v2/media/init_video_upload` |
| Brazil | `https://openplatform.shopee.com.br/api/v2/media/init_video_upload` |
| Test/Sandbox | `https://partner.test-stable.shopeemobile.com/api/v2/media/init_video_upload` |

### Common Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| partner_id | int |  | 1 | Partner ID is assigned upon registration is successful. Required for all requests. |
| timestamp | timestamp |  | 1610000000 | This is to indicate the timestamp of the request. Required for all requests. Expires in 5 minutes. |
| sign | string |  | e318d3e932719916a9f9ebb57e2011961bd47abfa54a36e040d050d8931596e2 | Signature generated by partner_id, api path, timestamp and partner_key via HMAC-SHA256 hashing algorithm. More details:  https://open.shopee.com/documents?module=87&type=2&id=58&version=2 |


### Request Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| business | int32 | ✅ | 3 | Defines the business type of the uploaded image. Supported values:&nbsp;3 = Video |
| scene | int32 | ✅ | 1 | Defines the purpose of the uploaded image under the specified business type.&nbsp;Supported values:&nbsp;- If business = 3 (Video): 1 = Shopee Video |
| file_name | string | ✅ | test_video_name.mp4 | Original video file name. |
| file_size | int64 | ✅ | 26214400 | Total video file size in bytes.&nbsp;Rules and restrictions by business and scene:&nbsp;- If business = 3 (Video) and scene = 1 (Shopee Video):&nbsp;Maximum 1GB. |
| duration | int32 | ✅ | 105 | Video duration in seconds.&nbsp;Rules and restrictions by business and scene:- If business = 3 (Video) and scene = 1 (Shopee Video): 1s~180s. |


### Response Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| error | string |  |  | Indicate error type if hit error. Empty if no error happened. |
| message | string |  |  | Indicate error details if hit error. Empty if no error happened. |
| warning | string |  |  | Indicate warning message you should take care. |
| request_id | string |  | e3e3e7f33ee88a7454c64e7a0b546e01 | The identifier for an API request for error tracking. |
| response | object |  |  |  |
| ↳ video_upload_id | string |  | sg-11110201-6kh48-mepm7a0ttcw3c3 | Unique upload session ID. |
| ↳ part_size | int64 |  | 10485760 | The size of each part. When uploading video chunks, the video must be split according to this part size for each upload request. |


### Request Example (Python)

```python
import requests
import json

url = "https://partner.shopeemobile.com/api/v2/media/init_video_upload?partner_id=partner_id&sign=sign&timestamp=timestamp"

payload=json.dumps({
  "business": 3,
  "duration": 105,
  "file_name": "test_video_name.mp4",
  "file_size": 26214400,
  "scene": 1
})
headers = {
  'Content-Type': 'application/json'
}
response = requests.RPCRequest("POST",url,headers=headers, data=payload, allow_redirects=False)

print(response.text)

```

### Request Payload

```json
{

	"scene": 1,
	"file_name": "test_video_name.mp4",
	"file_size": 26214400,
	"duration": 105
}
```

### Response Example

```json
{
	"error": "",
	"message": "",
	"warning": "",
	"request_id": "e3e3e7f33ee88a7454c64e7a0b546e01",
	"response": {
		"video_upload_id": "sg-11110201-6kh48-mepm7a0ttcw3c3",
		"part_size": 10485760
	}
}
```

### Error Example

```json
{
    "error": "error_param",
    "message": "The scene value does not match with business.",
    "request_id": "e3e3e7f33ee8a17b646c2bf8bdb51d01"
```

## v2.media.get_video_upload_result

**Method:** `GET`  
**Path:** `/api/v2/media/get_video_upload_result`

Use this API to retrieve the current status and result of a video upload task. You can also use video_upload_result_push to get notified immediately when a video upload reaches a final status (SUCCEEDED, FAILED, or CANCELLED).

### Endpoints

| Environment | URL |
| --- | --- |
| Production | `https://partner.shopeemobile.com/api/v2/media/get_video_upload_result` |
| Chinese Mainland | `https://openplatform.shopee.cn/api/v2/media/get_video_upload_result` |
| Brazil | `https://openplatform.shopee.com.br/api/v2/media/get_video_upload_result` |
| Test/Sandbox | `https://partner.test-stable.shopeemobile.com/api/v2/media/get_video_upload_result` |

### Common Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |

### Response Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |

Possible values:- INITIATED: Upload task has been created (via init_video_upload) but no parts have been uploaded yet.- UPLOADING: Video file parts are being uploaded.
