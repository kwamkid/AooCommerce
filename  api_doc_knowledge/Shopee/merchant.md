## v2.merchant.get_merchant_info

**Method:** `GET`  
**Path:** `/api/v2/merchant/get_merchant_info`

Use this call to get information of merchant

### Endpoints

| Environment | URL |
| --- | --- |
| Production | `https://partner.shopeemobile.com/api/v2/merchant/get_merchant_info` |
| Chinese Mainland | `https://openplatform.shopee.cn/api/v2/merchant/get_merchant_info` |
| Brazil | `https://openplatform.shopee.com.br/api/v2/merchant/get_merchant_info` |
| Test/Sandbox | `https://partner.test-stable.shopeemobile.com/api/v2/merchant/get_merchant_info` |

### Common Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| partner_id | int |  | 1 | Partner ID is assigned upon registration is successful. Required for all requests. |
| timestamp | timestamp |  | 1610000000 | This is to indicate the timestamp of the request. Required for all requests. Expires in 5 minutes. |
| access_token | string |  | c09222e3fc40ffb25fc947f738b1abf1 | The token for API access, using to identify your permission to the api. Valid for multiple use and expires in 4 hours. |
| merchant_id | int |  | 1 | Shopee’s unique identifier for a merchant. Required for all merchant level requests(CB CNSC user calling global product related APIs). |
| sign | string |  | e318d3e932719916a9f9ebb57e2011961bd47abfa54a36e040d050d8931596e2 | Signature generated by partner_id, api path, timestamp, access_token, merchant_id and partner_key via HMAC-SHA256 hashing algorithm. More details:  https://open.shopee.com/documents?module=87&type=2&id=58&version=2 |


### Response Parameters

| Field | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| merchant_name | string |  |  sellerplatform_uat_merchant | Name of the merchant. |
| auth_time | timestamp |  | 1608114596 | The timestamp when the merchant was authorized to the partner. |
| expire_time | timestamp |  | 1640342010 | Use this field to indicate the expiration date for merchant authorization. |
| request_id | string |  | a3a4277823b1019960cc92cfd972c506 | The identifier for an API request for error tracking. |
| merchant_currency | string |  | CNY | The three-digit code representing the currency unit used for the item in this merchant. If currency haven't been setting in CNSC/KRSC, it will be empty.China merchant support CNY and USD currently.Korea merchant support KRW and USD currently.&nbsp;Hong kong merchant support USD currently, will support HKD later. |
| merchant_region | string |  | KR | Region of the merchant. Including KR, HK and CN. |
| is_upgraded_cbsc | boolean |  | true | Use this filed to indicate whether this merchant is upgraded to cbsc. |
