## Upload File Init

To upload a large file to Tiktok Shop (e.g., a video), follow these three steps:
1. Initialize the upload session for the video.
2. Upload the video file to the TTS server. Files smaller than 5 MB must be uploaded as a single, non‑chunked request.
3. Call the API corresponding to the target path and pass the ResourceId returned in step 2 as a parameter.

For more detailed content, refer to the document:https://partner.tiktokshop.com/docv2/page/wfi3nz36

**Path:** `/open/202512/file/init`

**Method:** `POST`

**Common Parameters:** [Reference](https://partner.tiktokshop.com/docv2/page/678e3a4278f4c20311b8b57e)

**Common Error Codes:** [Reference](https://partner.tiktokshop.com/docv2/page/678e3a45786253031531b942)

The partner access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 3. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a3978f4c20311b8b555) to get partner access_token. |

// For more details about the SDK, refer to the documentation:
// https://partner.tiktokshop.com/docv2/page/67c83e0799a75104986ae498
func open202512UploadFileInitPost() {
    configuration := apis.NewConfiguration()
    configuration.AddAppInfo(appKey, appSecret)
    apiClient := apis.NewAPIClient(configuration)
    request := apiClient.OpenV202512API.Open202512FileInitPost(context.Background())
    request = request.XTtsAccessToken("your access token")
    request = request.ContentType("application/json")
    open202512UploadFileInitRequestBody := open_v202512.NewOpen202512UploadFileInitRequestBody()
    open202512UploadFileInitRequestBody.SetFileName("test.mp4")
    open202512UploadFileInitRequestBody.SetFileType("video")
    open202512UploadFileInitRequestBody.SetFileSize(1024)
    open202512UploadFileInitRequestBody.SetTotalChunkCount(1)
    open202512UploadFileInitRequestBody.SetTargetPath("[POST]/affiliate_creator/202505/videos")
    request = request.Open202512UploadFileInitRequestBody(*open202512UploadFileInitRequestBody)
    resp, httpResp, err := request.Execute()
    if err != nil || httpResp.StatusCode != 200 {
        fmt.Printf("productsRequest err:%v resbody:%s", err, httpResp.Body)
        return
    }
    if resp == nil {
        fmt.Printf("response is nil")
        return
    }
    if resp.GetCode()!= 0 {
        fmt.Printf("response business is error, errorCode:%d errorMessage:%s", resp.GetCode(), resp.GetMessage())
        return
    }
    respDataJson, _ := json.MarshalIndent(resp.GetData(), "", "  ")
    fmt.Println("response data:", string(respDataJson))
    return
}
