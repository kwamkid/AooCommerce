## Confirm Package Shipment 

This API enables a warehouse service provider to send package shipment information for an order. Only warehouse service providers who have been certified by the platform have permission to access this interface.

**Path:** `/supply_chain/202309/packages/sync`

**Method:** `POST`

**Common Parameters:** [Reference](https://partner.tiktokshop.com/docv2/page/678e3a4278f4c20311b8b57e)

**Common Error Codes:** [Reference](https://partner.tiktokshop.com/docv2/page/678e3a45786253031531b942)

### Request Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | Depends on the auth type of the API.  1. The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. 2. The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. 3. The partner access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 3. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a3978f4c20311b8b555) to get partner access_token. |

### Request Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

### Request Body Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| warehouse_provider_id | string | Y | Warehouse provider ID, unique and provided by TikTok |
| packages | []object | Y | Package info list |
| ^id | string | Y | Package ID |
| ^wms_order_id | string | Y | Warehouse Management System order number |
| ^provider_warehouse_code | string | N | Warehouse code |
| ^shipping_origin_city | string | N | Origin city name for the shipment |
| ^time_zone | string | Y | The warehouse time zone |
| ^ship_time_millis | int | Y | Time when the order is shipped out of the warehouse (Unix timestamp in milliseconds) |
| ^create_time_millis | int | Y | Time when warehouse receives the order (Unix timestamp in milliseconds) |
| ^handover_time_millis | int | Y | Time when the order is handed over to the shipping provider (Unix timestamp in milliseconds) |
| ^shipping_provider_id | string | Y | Shipping service provider ID |
| ^shipping_provider_name | string | Y | Shipping service provider name |
| ^tracking_number | string | Y | Tracking number |
| ^dimension | object | Y | Package dimension information |
| ^^length | int | N | Package length value |
| ^^width | int | N | Package width value |
| ^^height | int | N | Package height value |
| ^^unit | string | N | Package dimension unit Possible values: - METER - CENTIMETER - MILLIMETER - MICRON - FOOT - INCH |
| ^weight | object | N | Package weight information |
| ^^value | int | N | Package weight value |
| ^^unit | string | N | Package weight unit Possible values: - KILOGRAM - GRAM - MILLIGRAM - POUND - OUNCE |
| ^skus | []object | Y | List of order SKUs  |
| ^^id | string | Y | TikTok Shop SKU ID |
| ^^quantity | int | Y | The quantity of each SKU |
| ^provider_warehouse_name | string | N | Warehouse name |
| ^tcw_warehouse_type | string | N | TikTok warehouse type  Possible values: - STANDARD: Standard warehouse that has not been specifically certified by TikTok  - TIKTOK_CERTIFIED_WAREHOUSE_FULFILLMENT: TikTok certified warehouse usually offering better service levels. Certified warehouses are required to meet fulfillment timeline standards set by TikTok |
