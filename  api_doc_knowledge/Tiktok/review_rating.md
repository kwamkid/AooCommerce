## UploadReviewMedia

Upload media files (e.g. images, videos) that are associated with product reviews from external sources.

**Path:** `/review_rating/202410/media/upload`
**Method:** `POST`
**Version:** 202410
**Docs:** https://partner.tiktokshop.com/docv2/page/upload-review-media-202410

| Name | Type | Required | Description |
| --- | --- | --- | --- |

## ImportProductReviews

Import product reviews from external sources to TikTok Shop.
Sellers with popular products on other platforms can overcome the cold start on TikTok Shop by showcasing verified external reviews to build greater trust in the products and help customers make informed purchasing decisions.
**Note**
- Imported reviews cannot be edited, updated, nor deleted, therefore please exercise caution during import. To make any changes, you need to submit a request through the Seller Center, and all requests are subject to TikTok Shop's approval.
- Use the [Upload Review Media API] to upload review images or videos first and obtain the URIs before calling this API.

**Path:** `/review_rating/202410/product_reviews`
**Method:** `POST`
**Version:** 202410
**Docs:** https://partner.tiktokshop.com/docv2/page/import-product-reviews-202410

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| shop_cipher | string |  | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. |

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-tts-access-token | string | Y |  |
| Content-Type | string | Y | Allowed type: application/json |

### Request Body (`application/json`)

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| product_review | object |  | Product review information based on existing reviews from an external source. |
| ^product | object |  | The product being reviewed. |
| ^^identifier | string |  | An identifier used to associate the product between TikTok Shop and the external platform. Format for each identifier type: - TIKTOK_PRODUCT_ID: Get the value from the `products.id` returned in the [Search Products API](65854ffb8f559302d8a6acda) - EXTERNAL_PRODUCT_ID: Max 19 digits - PRODUCT_IDENTIFIER_CODE: 8, 12, 13, 14 digits, or exactly 9 digits followed by an uppercase `X` **Note**: This identifier must be associated with **only one** TikTok Shop product. The API request will fail if multiple products share the same identifier. Please update the relevant products and try again. |
| ^^identifier_type | string |  | The identifier type of the product being reviewed. Possible values: - TIKTOK_PRODUCT_ID: A product ID generated by TikTok Shop. This is equivalent to the `products.id` returned in the [Search Products API](65854ffb8f559302d8a6acda). Intended for use by connector app developers. - EXTERNAL_PRODUCT_ID: An external product or SKU identifier used in an external ecommerce platform. - PRODUCT_IDENTIFIER_CODE: An internationally regulated identifier code, including GTIN, EAN, UPC, or ISBN. **Recommendations** - We suggest that you use TikTok Shop product IDs, if available, for precise matching. - The system will attempt to match the non-TikTok Shop identifiers (e.g. Shopify product ID, GTIN, UPC, EAN, ISBN), but there may be no match if these values were not included during the creation of the TikTok Shop product. Please add or edit the external identifiers in the relevant product to align with the ones used in the reviews. |
| ^^name | string |  | The product name. Max length: 255 characters |
| ^review_records | array<object> |  | The list of reviews to import for the product. Max count: 50 |
| ^^content | string |  | The review content. Max length: 5000 characters |
| ^^create_time_millis | integer |  | The time when the review is created. Unix timestamp. Unit: Millisecond |
| ^^external_review_id | string |  | The review ID from the import source. Max length: 19 digits **Note**: This ID must be **unique** across reviews. The API request will fail if this ID is duplicated or has been imported before in a different review record. |
| ^^image_uris | array<string> |  | The URIs of images associated with the review, delimited by commas. Retrieve the URIs from the [Upload Review Media API]. Max count: 6 (5 if you are adding a video) |
| ^^rating | integer |  | The review rating, where 1 indicates the worst rating and 5 indicates the best rating. Valid range: [1, 5] |
| ^^reviewer_display_name | string |  | The reviewer name to be displayed on TikTok Shop's product display page. On the product display page, it will appear partially masked for privacy. Max length: 32 characters |
| ^^source | string |  | The name of the import source. Max length: 32 |
| ^^title | string |  | The review title. Max length: 50 characters |
| ^^video_uris | array<string> |  | The URIs of videos associated with the review, delimited by commas. Retrieve the URIs from the [Upload Review Media API]. Max count: 1 |

| request_id | string |  | Request log. |
